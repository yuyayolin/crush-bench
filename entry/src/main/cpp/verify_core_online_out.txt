[C] 恢复逻辑镜像: C 类拉起(备份 -> 写 -> 读回 -> 恢复)
====================================================================================================
  C 类核, 应用无权限(打开 online 就 EACCES=13)                   -> wrote=0 writeErrno=13 after=0 restoreWrote=0 final=0 restoreOk=1 open-failed
  C 类核, 应用无权限(EPERM=1)                                 -> wrote=0 writeErrno=1 after=0 restoreWrote=0 final=0 restoreOk=1 open-failed
  C 类核, 只读文件系统(EROFS=30)                               -> wrote=0 writeErrno=30 after=0 restoreWrote=0 final=0 restoreOk=1 open-failed
  C 类核, 打开成功但写返回 0 个字节(errno=13)                       -> wrote=1 writeErrno=13 after=0 restoreWrote=0 final=0 restoreOk=1 still-offline
  C 类核, 写返回 1 个字节但读回仍是 0(内核忽略了写)                       -> wrote=1 writeErrno=0 after=0 restoreWrote=0 final=0 restoreOk=1 still-offline
  C 类核, 写成功且读回变成 1(真的拉起来了) -> 必须恢复成 0                  -> wrote=1 writeErrno=0 after=1 restoreWrote=1 final=0 restoreOk=1 lifted
  在线核(A 类)也做同一次写探测: 写后读回仍是 1, 值没变 -> 不回写               -> wrote=1 writeErrno=0 after=1 restoreWrote=0 final=1 restoreOk=1 lifted
  没有 cpuN/online 文件(不支持热插拔) -> 不写、不报成功                 -> wrote=0 writeErrno=0 after=0 restoreWrote=0 final=0 restoreOk=1 no-online-file

  [PASS] C3 写返回 0 个字节时(cWriteFail 路径)不算拉起来
